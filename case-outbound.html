Three decisions that shaped it

01

Preview beside the editor

The preview updates as you type, so nobody sends a message they have not seen.

02

Type % to personalise

Visitor details drop into a message with one keystroke, no syntax to learn.

03

Frequency is part of the plan

Start, end and how often are set with the campaign, so reaching out never turns into spamming.
