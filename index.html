How the system ships

Figma to code without the gap. Five steps, one source of truth.

  2. 01

    Tokens

    Colour, type, space and radius as Figma variables with light and dark modes.

  3. →
  4. 02

    Components

    48+ components built on the tokens, documented and governed.

  5. →
  6. 03

    Code Connect

    Each component mapped to its real code, so Dev Mode shows the truth.

  7. →
  8. 04

    Figma MCP

    Agents read the mappings and generate production components with Claude.

  9. →
  10. 05

    Ship

    Same component across web, mobile SDK and WhatsApp. Zero drift.

Story

The best compliment my work gets is when a non-technical user sets something up without asking for help.

I joined Zoho as an intern in 2018 and have designed SalesIQ ever since: research, UX, visual design and the design system that keeps it consistent. Lately I'm obsessed with the layer between design and code. My day-to-day is Figma variables, design tokens and Code Connect, and I'm building AI-assisted workflows with Claude and Figma MCP that generate a design system twice: once as a Figma library, once as production components. Outside the product I make user-education videos for SalesIQ shown at Zoholics, partner events and meetups.

  • 2024 — now Senior Visual Designer (Product Design), Zoho SalesIQ Design system owner, Figma MCP and Code Connect, Operator Console
  • 2018 — 2024 Visual Designer, Zoho SalesIQ Zobot, Reports, Proactive Chat, Brand, Outbound, Push, Feedback
  • 2018 Visual Designer intern, Zoho
  • 2014 — 2017 BCA, Computer Applications Kongu Arts and Science College, Bharathiar University
