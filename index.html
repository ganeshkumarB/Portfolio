04 / How I work

Clarity through systems. Better through collaboration.

I simplify complex product problems, build reusable systems, and explore how AI can bring design closer to code.

One section. Four steps.

Six symptoms usually point at one cause. I map them with the team before drawing anything.

Flows first. The pieces that repeat across them become the patterns, and the patterns become components.

Tokens leave Figma through MCP and land in code without anyone retyping them. One token, both sides.

A prompt goes in, Figma MCP reads the tokens, Code Connect returns the code. A re-enactment, not a recording.
