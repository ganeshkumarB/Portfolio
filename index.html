Five steps, one source of truth.

    Components

    Every component built on the tokens, documented and governed.

  5. →

Story

      
The best compliment my work gets is when a non-technical user sets something up without asking for help.

      
Zoho intern in 2018, SalesIQ designer ever since: research, UX, visual design and the system that keeps it consistent. These days I live in the layer between design and code, with Figma variables, Code Connect and AI workflows that generate the system twice: as a Figma library and as production components.
